# Paper Lantern

**영어 논문 PDF를 원문과 한국어 번역으로 나란히 읽는 Chrome 확장 프로그램입니다.**

Chrome 내장 Translator API로 문장을 번역하고, 원문과 번역문의 위치를 연결합니다. 웹 PDF와 로컬 PDF를 지원하며, 원본 PDF 탭을 유지한 채 읽기 화면을 제공합니다.

Codex를 연결하면 문맥을 활용한 번역과 논문 질문도 사용할 수 있습니다. 기본 번역 엔진은 Chrome이며, 상단에서 원하는 엔진을 선택합니다.

## 주요 기능

- **영한 자동 번역** — PDF를 열면 모델 준비와 전체 페이지 번역을 시작합니다. 중단한 번역은 이어서 진행할 수 있습니다.
- **문장 연결 하이라이트** — 원문이나 번역문에 커서를 올리면 대응하는 문장이 강조됩니다.
- **본문 중심 추출** — 반복 머리말·쪽번호·arXiv 여백 문구·그림과 표의 내부 글자·캡션을 번역에서 제외하도록 분석합니다.
- **인용 논문 팝업** — `[12]`, `[2, 19]`, `[3–5]` 같은 인용을 클릭하면 PDF 안의 참고문헌 정보를 표시합니다.
- **기본 리더 전환** — 왼쪽 아래 토글로 Paper Lantern과 Chrome 기본 PDF 리더를 전환합니다.
- **Codex 문장 복원·번역** — PDF 전체에서 추출한 텍스트를 한 요청으로 보내고 정리된 원문·번역 쌍을 받습니다. 원문 하이라이트는 결과를 받은 뒤 로컬에서 연결하며, 매칭에 실패해도 번역은 표시합니다.
- **Codex 질문** — 항상 논문 전체를 참고해 질문에 답합니다. 답변의 페이지 버튼으로 근거 위치를 열 수 있습니다.
- **드래그해서 질문** — PDF 텍스트를 드래그하고 **Codex에게 질문**을 누르면 선택한 내용 옆에 대화 팝업을 엽니다. 논문 전체를 배경 문맥으로 참고하며, 창 이동·크기 조절·접기·다시 열기와 선택별 대화·초안 저장을 지원합니다.
- **Codex 설정** — 번역·질문의 기본 모델과 시스템 프롬프트를 각각 지정합니다.
- **세션 자동 저장** — 같은 PDF를 다시 열면 번역·질문 내역·마지막 페이지·패널 상태를 복원하고 미완료 번역만 이어서 진행합니다.
- **페이지 간 문장 연결** — 페이지 경계에서 끊긴 본문을 연결해 한 번만 번역하고 양쪽 페이지에서 하이라이트합니다.
- **접을 수 있는 패널** — 상단 **번역**, **Codex 질문** 버튼으로 각 패널을 접고 펼칩니다.

## 시작하기

### 사용 환경

- Chrome 내장 Translator API를 사용할 수 있는 데스크톱 환경
- 영어 텍스트를 선택할 수 있는 PDF, 최대 **100MB**
- 최초 번역 모델 다운로드를 위한 인터넷 연결

### 설치

**[Paper Lantern v0.5.2 다운로드](https://github.com/JBlimp/paper_lantern/raw/refs/heads/main/releases/paper-lantern-0.5.2.zip)**

패키지 ZIP을 받았다면 압축을 풉니다. 소스에서 설치하려면 먼저 아래 [개발](#개발)의 빌드를 실행합니다.

1. Chrome에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. `manifest.json`이 있는 폴더를 선택합니다. 소스에서 빌드했다면 `dist/`입니다.
5. 로컬 PDF를 사용하려면 **Paper Lantern → 세부정보 → 파일 URL에 대한 액세스 허용**을 켭니다.

다른 PDF 뷰어 확장 프로그램이 화면을 교체하고 있다면 충돌을 피하기 위해 꺼 두세요.

### PDF 열기

- **로컬 파일:** Chrome에서 `Ctrl+O`로 PDF를 엽니다.
- **웹 파일:** 브라우저에서 원본 PDF 링크를 엽니다.

PDF 탭에 좌우 리더가 표시되고 번역을 자동으로 시도합니다. Chrome이 모델 시작에 사용자 동작을 요구하면 **새로고침**을 누릅니다.

확장 아이콘은 현재 PDF 탭에 리더를 추가합니다. PDF가 아닌 탭에서는 안내 화면을 엽니다. 안내 화면의 **파일 선택 (독립 리더)**으로도 번역할 수 있지만, 이 경우 원본 PDF 탭을 유지하는 방식은 사용하지 않습니다.

### Codex 연결 (선택 사항 · Windows)

1. **Node.js 22.17 이상**과 **Codex**를 설치하고, Codex에서 ChatGPT 계정으로 로그인합니다.
2. Chrome에 Paper Lantern 확장을 로드합니다.
3. 배포 폴더의 `companion/install.cmd`를 실행합니다. 설치된 확장 ID를 자동으로 찾아 등록합니다. 관리자 권한은 필요하지 않습니다.
4. 리더를 열면 Codex에 자동 연결됩니다. 상단 **설정**에서 번역·질문의 기본 모델을 지정합니다.
5. 번역에 사용하려면 상단에서 **Codex 번역**을 선택합니다.

API 키나 상시 실행하는 서버는 필요하지 않습니다. Chrome이 연결 프로그램을 필요할 때 실행합니다. 확장 ID 또는 Codex 실행 경로가 바뀌면 설치를 다시 실행하세요. 자세한 내용은 [연결 프로그램 안내](companion/README.md)를 참고하세요.

**이전 버전에서 업데이트한다면 `companion/install.cmd`도 다시 실행하세요.** 자동 연결과 여러 탭의 요청 처리를 위해 연결 프로그램 업데이트가 필요합니다.

Chrome 프로필마다 연결 프로그램과 `codex app-server` 하나를 실행해 모든 PDF 탭이 공유합니다. 탭을 닫거나 해당 탭의 **연결 해제**를 눌러도 다른 탭은 계속 사용할 수 있으며, 마지막 탭을 닫아도 연결을 유지합니다. Chrome 종료 또는 확장 새로고침 시 종료됩니다. 별도 서버 수동 실행이나 로컬 HTTP 포트는 필요하지 않습니다. 서로 다른 Chrome 프로필은 별도 프로세스를 사용합니다.

PC 연결 프로그램은 트레이 아이콘에서 **라이브러리 열기**, **상태 보기**, **Codex 서버 재시작**, **연결 프로그램 종료**를 제공합니다. 더블클릭해도 라이브러리를 엽니다. 종료 시 Paper Lantern이 실행한 서버만 정리합니다. 다시 사용하려면 시작 메뉴의 **Paper Lantern**을 실행하면 리더가 자동으로 재연결합니다. **모델 목록 다시 불러오기**로 즉시 연결할 수도 있습니다. 설치 폴더의 `companion/start.vbs`로도 실행할 수 있습니다. Windows 로그인 시 자동 실행은 등록하지 않습니다.

모델 목록에 기본값만 표시된다면 연결이 완료되지 않은 상태입니다. 설정에서 실제 연결 오류와 현재 확장 ID를 확인할 수 있습니다. **모델 목록 다시 불러오기**로 재연결하며, 정상 연결 시 사용 가능한 모델과 계정 기본 모델 이름이 표시됩니다. 모델 목록과 별도의 상태 확인 요청으로 실제 연결을 확인합니다. 설정에 연결 프로그램 버전도 표시합니다. 연결 중에는 5초 간격으로 상태를 확인하며, 10초 동안 응답이 없으면 연결 실패로 표시합니다. 탭으로 돌아왔을 때도 재확인합니다. 라이브러리 창만 닫으면 연결은 유지되고, 트레이의 **연결 프로그램 종료**는 연결과 자동 재시작을 중지합니다.


번역·질문의 기본 모델은 각각 설정할 수 있으며, 지정하지 않으면 Codex 계정의 기본 모델을 사용합니다. 모델·프롬프트 변경은 다음 요청부터 적용되고 이미 완료된 번역은 유지됩니다. **새로고침**을 누르면 Codex는 논문 전체 번역을 다시 요청합니다. Chrome 로컬 번역은 미완료 문장부터 이어가며, 완료 상태에서는 새로 번역합니다.

Chrome 번역은 로컬 모델, Codex는 로그인한 계정의 온라인 모델과 사용량을 이용합니다. Codex 요청은 ephemeral thread로 처리하고, 이어지는 질문에는 저장된 최근 대화와 논문 문맥을 전달합니다.

Codex 번역은 논문 전체를 한 요청으로 처리하며 단어 ID나 묶음을 모델에 전달하지 않습니다. 원문·번역·페이지 정보만 받고 원문 매칭은 로컬에서 시도합니다. PDF 파일 직접 첨부나 OCR은 지원하지 않으며, 추출한 텍스트를 사용합니다. 긴 논문은 결과를 받을 때까지 수 분이 걸릴 수 있습니다.

선택 질문 팝업은 PDF 페이지에 위치를 저장하므로 스크롤·확대·축소를 따라갑니다. 접힌 카드도 드래그할 수 있고 클릭하면 다시 열립니다. 이동 중에는 질문한 원문이 하이라이트됩니다. 채팅 답변은 Markdown 제목·목록·표·코드 블록으로 표시되며, 입력창 아래에서 질문 기본 모델을 바로 바꿀 수 있습니다.

로컬 프로그램이 실행되면 Chrome의 Default/Profile 프로필에 설치된 Paper Lantern 확장을 자동 탐지하고 연결을 등록합니다. **확장 자동 연결** 버튼으로 즉시 재확인할 수도 있습니다. ID 입력은 필요하지 않으며 기존 ID와 저장 데이터는 유지됩니다. 연결되지 않았던 리더는 15초 간격으로 재시도합니다. 직접 연결 해제를 누르면 자동 재연결을 멈춥니다.

자동 등록이 어려운 환경에서는 로컬 프로그램의 **수동 연결**에서 확장 설정에 표시된 ID를 붙여넣어 등록할 수 있습니다. 로컬 프로그램 하단은 ID 등록 상태와 실제 리더 연결 상태를 구분해 표시합니다. 확장 연결 실패의 원인은 채팅창에도 표시됩니다.

### 로컬 논문 라이브러리

PDF를 연 것만으로는 보관하지 않습니다. 리더 상단 **라이브러리에 추가**를 누르면 현재 PDF를 PC에 복사해 보관합니다. 시작 메뉴의 **Paper Lantern** 또는 트레이 아이콘 더블클릭으로 라이브러리를 열 수 있습니다.

- PDF 여러 개 추가, 파일 드래그로 가져오기, 제목·파일 이름 검색
- 폴더와 하위 폴더 생성·이름 변경, 논문을 폴더로 드래그하여 분류
- 동일 논문을 여러 폴더에 분류해도 PDF는 한 번만 저장
- 폴더 삭제·폴더에서 빼기는 보관된 PDF를 지우지 않음
- 휴지통과 복원, 제목 수정, 더블클릭하여 Chrome 리더에서 열기

보관 위치는 `%LOCALAPPDATA%\PaperLantern\library`입니다. `files`에 PDF 사본, `index.json`에 제목·분류를 보관하며 이전 목록은 `index.json.bak`에 남깁니다. 원본 파일은 변경하지 않습니다. 라이브러리를 백업하려면 이 폴더 전체를 복사하세요. 기존 번역·대화는 같은 Chrome 프로필의 확장 프로그램 저장소에서 이어집니다. 현재는 파일 이름을 초기 제목으로 사용하며 DOI·저자 자동 조회와 Zotero 동기화는 포함하지 않습니다.

### 저장과 이어 읽기

번역·대화·마지막 페이지·패널 상태를 확장 프로그램의 IndexedDB에 자동 저장합니다. 라이브러리에 명시적으로 추가하지 않은 PDF 파일은 복사하지 않습니다. 동일한 파일을 다시 열면 이름이나 경로가 달라져도 파일 내용의 SHA-256 값으로 이전 세션을 찾습니다. 내용이 바뀐 파일은 새 세션으로 시작합니다.

완료된 번역은 모델을 다시 실행하지 않고 표시합니다. Chrome 번역은 저장된 문장부터 이어가고, Codex 번역은 완성된 전체 결과를 저장합니다. Codex 요청을 중단하면 다음 시도는 논문 전체를 다시 처리합니다. 설정은 브라우저 로컬 저장소에 별도로 보관합니다. 저장 공간이 부족하거나 저장소를 사용할 수 없으면 알림을 표시하고 현재 탭에서 계속 읽을 수 있습니다. 다른 Chrome 프로필이나 컴퓨터로 자동 동기화되지는 않습니다.

페이지 경계 연결은 본문의 읽기 순서, 위치, 글자 크기와 문장 끝을 기준으로 판단합니다. 제목·캡션·목록과 완결된 문장은 합치지 않습니다. 특이한 레이아웃이나 잘못 추출된 PDF 텍스트에서는 판단이 정확하지 않을 수 있습니다.

질문은 PDF 전체 텍스트와 캡션을 근거로 답합니다. **이미지 설명**을 누르고 한 페이지 안의 그림 영역을 드래그하면, 선택 이미지와 논문 전체 텍스트를 함께 사용하는 팝업 채팅이 열립니다. 질문을 입력해 전송하면 되며, Esc나 버튼을 다시 눌러 선택을 취소할 수 있습니다. 선택 이미지도 대화와 함께 저장되어 후속 질문과 재열기에 사용됩니다. 문서 전체의 OCR은 아직 지원하지 않습니다. 입력 한도를 넘는 논문은 자동으로 나누거나 생략하지 않고 오류를 표시하며, 전문 용어 유지와 페이지 근거의 정확성은 모델 응답에 따라 달라질 수 있습니다.

## 개발

Node.js 22.17 이상과 npm을 사용합니다.

```sh
npm ci
npm run build
npm test
npm run format:check
```

빌드 결과는 `dist/`에 생성됩니다. Chrome 확장 관리 화면에서 이 폴더를 로드하면 됩니다. Chrome 번역만 사용하는 경우 Node.js 설치 없이 위의 ZIP으로 설치할 수 있습니다.

개발 화면은 `npm run dev`로 실행합니다. PDF 탭 주입과 토글은 Chrome에 확장을 로드한 상태에서 확인하세요.

브라우저 테스트에는 설치된 Chrome이 필요합니다.

```sh
npm run test:e2e
node tests/auto-connect.mjs
node tests/codex-ui.mjs
node tests/sessions.mjs
node tests/codex-segmentation.mjs
node tests/floating-chat.mjs
node tests/region-chat.mjs
node tests/library-ui.mjs
node --test tests/library-transfer.test.mjs
node tests/bodyPipeline.mjs
node tests/citations.mjs
```

실제 모델과 원본 PDF 탭 통합 테스트는 `node tests/pdf-tab.mjs`로 실행합니다. 먼저 `npm run test:e2e`로 테스트 PDF를 준비하세요. 최초 모델 다운로드에는 인터넷이 필요합니다.

Codex 실제 연결 테스트는 `node tests/codex-native.mjs --real`입니다. 현재 계정으로 테스트 문장의 번역·질문을 실행하며, `dist/` 확장 ID를 연결 프로그램에 등록합니다. 사용자 Chrome 프로필 대신 격리된 테스트 프로필을 사용합니다.

선택 영역의 실제 이미지 전달은 `node tests/region-chat.mjs --real`로 검증할 수 있습니다. 격리된 Chrome 프로필에서 합성 그래프의 색상을 질문하며 로그인한 Codex 계정을 사용합니다.

## 배포 파일

- `src/`, `public/` — 확장 프로그램 소스
- `tests/` — 문장 추출·인용 연결·브라우저 테스트
- `scripts/` — 빌드 리소스 패키징과 개발 도구
- `companion/` — Windows Codex 연결 프로그램과 설치 스크립트
- `releases/` — 설치용 ZIP과 SHA-256 체크섬

업데이트할 때는 설치 폴더의 파일을 교체한 뒤 확장 프로그램과 PDF 탭을 모두 새로고침하세요. 배포 의존성의 라이선스는 ZIP 안의 `licenses/`에 포함됩니다.
